LaTeXSnippermacOS Office 插件帮助

在 Word 和 PowerPoint 中使用 LaTeX 公式

插件页面由正在运行的 LaTeXSnipper 桌面端提供。公式编辑和渲染在本机完成；截图识别复用桌面端的识别结果。

开始使用

1启动桌面端

在 LaTeXSnipper“设置”中启用“Office 插件”。插件只在桌面端运行时可用。

2打开选项卡

重新打开 Word 或 PowerPoint，在“开始 › 加载项”中选择 LaTeXSnipper，功能区随后出现 LaTeXSnipper 选项卡。

3插入公式

点击“插入公式”打开编辑器，Shift + Enter 插入或更新公式。

首次启用时，macOS 会请求信任一张仅用于 localhost 的证书。Office 只能通过 HTTPS 加载插件页面，此证书不能签发其他证书，也不会用于本机以外的地址。

Word 操作

  • 插入方式：默认插入 Word 原生公式（OMML），也可在设置中切换为 SVG 图片。原生公式由 Word 排版，SVG 图片与 Windows 版 OLE 公式使用同一渲染结果。
  • 加载所选：把光标放在公式内或选中公式，点击“加载所选”在编辑器中修改，更新时保持原插入方式。
  • 删除所选 / 格式化：可处理选区内的多个公式；“格式化全部”将文档中的全部插件公式重置为当前默认样式。
  • 行间公式：状态窗格中勾选“行间公式”后插入，公式独占一段。

PowerPoint 操作

  • 插入方式：默认插入矢量 SVG 图片，也可切换为 PNG 图片。完整源码与样式保存在形状标签中，格式与 Windows 版相同，可在两个平台之间互相加载。
  • 更新：保持公式的位置和用户调整过的缩放比例；“格式化”命令恢复自然尺寸。

截图识别

先在桌面端“设置”中开启“自动化接口”。点击“截图识别”后，用 LaTeXSnipper 的截图快捷键框选公式；识别结果会载入状态窗格，确认后再插入。再次点击按钮可取消等待。

与 Windows 版的区别

Office for Mac 不支持 VSTO 和自定义 OLE 对象，因此以下功能目前只在 Windows 版提供：OLE 公式对象与双击编辑、MathType 互转、Word 自动编号与交叉引用、全文 LaTeX 解析。Windows 版插入的 OLE 公式在 Mac 上显示为图片，不能加载编辑。

LaTeX formulas in Word and PowerPoint

The add-in pages are served by the running LaTeXSnipper desktop app. Editing and rendering stay on this Mac; screenshot OCR reuses the desktop recognition result.

Getting started

1Start the desktop app

Enable “Office add-in” in LaTeXSnipper Settings. The add-in works only while the desktop app is running.

2Open the tab

Reopen Word or PowerPoint and choose LaTeXSnipper from Home › Add-ins. The LaTeXSnipper ribbon tab appears.

3Insert a formula

Click Insert Formula to open the editor. Shift + Enter inserts or updates it.

The first time, macOS asks you to trust a certificate that is valid only for localhost. Office loads add-in pages only over HTTPS; this certificate cannot sign other certificates.

Word

  • Insertion: native Word equations (OMML) by default, or SVG pictures. SVG pictures use the same rendering as the Windows OLE formulas.
  • Load Selected: place the cursor in a formula and edit it; updates keep its insertion kind.
  • Delete / Format: work on every formula in the selection; Format All resets every plugin formula to the current defaults.

PowerPoint

  • Insertion: vector SVG pictures by default, or PNG. Source and style are stored in the Windows shape-tag format, so formulas load on either platform.
  • Updates keep position and your resize scale; Format restores the natural size.

Screenshot OCR

Enable the Automation API in desktop Settings. Click Screenshot OCR, then capture the formula with the LaTeXSnipper shortcut. The result loads into the status pane. Click again to cancel.

Differences from Windows

Office for Mac does not support VSTO or custom OLE objects, so these remain Windows-only: OLE formula objects and double-click editing, MathType conversion, Word numbering and cross-references, and document-wide LaTeX parsing. OLE formulas from Windows display as pictures on Mac and cannot be loaded.
